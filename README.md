# FastenFinance

This repository hosts a lightweight static dashboard for monitoring selected financial indicators.

## Live site
The published GitHub Pages site is available at:

https://fasten90.github.io/FastenFinance/

## What the page shows
- USD → HUF and EUR → HUF exchange rates
- CNN Fear & Greed Index status
- Basic market open/closed status for major exchanges
- Small charts for recent exchange rate and sentiment history

## Technologies
- HTML
- CSS
- JavaScript
- Chart.js (loaded from a CDN)

## How to use
Open the site in a browser to view the latest data. The page loads live data from public APIs when available.

## Notes
- This project is designed to run as a static GitHub Pages site.
- No build step is required for everyday edits.
- If you change the page structure or scripts, make sure the site still works correctly in a browser.
